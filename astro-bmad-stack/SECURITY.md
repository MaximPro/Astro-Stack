## Reporting a Vulnerability

We take the security of Astro BMAD Stack seriously. If you believe you have found a security vulnerability, please report it to us as described below.

### Please Do NOT:

- Open a public GitHub issue
- Discuss the vulnerability in public forums
- Exploit the vulnerability

### Please DO:

1. **Report via GitHub Security Advisories**
   - Go to the Security tab
   - Click "Report a vulnerability"
   - Fill out the form with details

2. **Include in your report:**
   - Type of vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)
   - Your contact information

3. **Response timeline:**
   - Initial response: Within 48 hours
   - Status update: Within 7 days
   - Fix timeline: Depends on severity

### Severity Levels

#### Critical
- Remote code execution
- Authentication bypass
- Data exposure
- **Response:** Immediate (24-48 hours)

#### High
- XSS vulnerabilities
- CSRF vulnerabilities
- Privilege escalation
- **Response:** 7 days

#### Medium
- Information disclosure
- Denial of service
- **Response:** 14 days

#### Low
- Minor security improvements
- **Response:** 30 days

## Security Best Practices

When using Astro BMAD Stack:

### 1. Dependencies

```bash
# Regularly update dependencies
npm update

# Check for vulnerabilities
npm audit

# Auto-fix vulnerabilities
npm audit fix
```

### 2. Environment Variables

- **Never commit `.env` files**
- Use `.env.example` as template
- Rotate secrets regularly
- Use different secrets for dev/prod

### 3. Content Security Policy

Add to your deployment config:

```toml
# netlify.toml / wrangler.toml
[[headers]]
  for = "/*"
  [headers.values]
    Content-Security-Policy = "default-src 'self'; script-src 'self' 'unsafe-inline' https://trusted-cdn.com"
    X-Frame-Options = "DENY"
    X-Content-Type-Options = "nosniff"
    Referrer-Policy = "strict-origin-when-cross-origin"
```

### 4. BMAD-METHOD Security

- Review code generated by AI agents
- Don't commit sensitive data in BMAD configs
- Use `.gitignore` for `bmad/_cfg/secrets/`
- Validate all AI-generated code

### 5. Build Security

```bash
# Verify build integrity
npm run check

# Check for type safety issues
npm run build
```

### 6. Deployment Security

- **Enable HTTPS** (automatic on Cloudflare/Netlify)
- **Use security headers** (included in configs)
- **Enable rate limiting** (platform-dependent)
- **Monitor access logs**

## Known Security Considerations

### AI-Generated Code

⚠️ **Important:** BMAD-METHOD uses AI to generate code. Always:

1. **Review all generated code**
2. **Test thoroughly**
3. **Validate inputs/outputs**
4. **Check for injection vulnerabilities**

### Third-Party Dependencies

We use:
- Astro (official, well-maintained)
- React (Meta, well-maintained)
- Tailwind CSS (Tailwind Labs, well-maintained)
- BMAD-METHOD (Community, alpha version)

**Note:** BMAD-METHOD is in alpha. Review updates carefully.

### Static Site Security

Astro generates static sites by default, which are inherently more secure than dynamic sites. However:

- **Client-side code** runs in browser (validate user input)
- **Environment variables** can leak if prefixed with `PUBLIC_`
- **Build-time secrets** should never be committed
