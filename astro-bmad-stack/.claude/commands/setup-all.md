# Complete Setup

I'll set up everything you need:

## Steps

### 1. Install Dependencies (30 sec)
```bash
npm install
```

### 2. Initialize BMAD-METHOD (30 sec)
```bash
npm run bmad:install
```

This creates the `bmad/` folder with:
- 19+ specialized AI agents
- 50+ guided workflows
- Customization configs

### 3. Start Development Server (5 sec)
```bash
npm run dev
```

Opens at: http://localhost:4321

## What You'll Get

After setup:
- ✅ All dependencies installed
- ✅ BMAD-METHOD ready
- ✅ Dev server running
- ✅ Ready to build websites

## Usage After Setup

Try these slash commands:
- `/landing` - Create landing page
- `/saas` - Create SaaS site
- `/portfolio` - Create portfolio
- `/blog` - Create blog
- `/component` - Create component

Or use BMAD workflows:
- `/bmad-quick` - Quick Flow
- `/bmad-full` - Full Method
- `/bmad-party` - Multi-agent
