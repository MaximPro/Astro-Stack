## What You Can Do

### 🎯 One-Click Website Templates

Use slash commands to instantly create:

| Command | Creates | Time |
|---------|---------|------|
| `/landing` | Complete landing page | 2 min |
| `/saas` | SaaS landing with pricing | 3 min |
| `/portfolio` | Portfolio/agency site | 2 min |
| `/blog` | Blog with CMS ready | 4 min |
| `/ecommerce` | E-commerce storefront | 5 min |

### 🤖 BMAD-METHOD Workflows

| Command | Purpose |
|---------|---------|
| `/bmad-setup` | Initialize BMAD-METHOD |
| `/bmad-quick` | Quick Flow (features/fixes) |
| `/bmad-full` | Full BMad Method workflow |
| `/bmad-party` | Party Mode (multi-agent) |

### ⚡ Quick Actions

| Command | Action |
|---------|--------|
| `/dev` | Start development server |
| `/build` | Build for production |
| `/deploy-cf` | Deploy to Cloudflare |
| `/deploy-netlify` | Deploy to Netlify |
| `/component` | Create new component |
| `/page` | Create new page |
