## 🎯 5-Minute Setup

**1. Start (pick one):**
- Click StackBlitz button above (fastest)
- OR run: `npx degit MaximPro/Astro-Stack/app my-landing`

**2. Edit content:**
```astro
<!-- app/src/pages/index.astro -->
<Hero
  headline="Your Headline"
  subheadline="Your Subheadline"
/>
```

**3. Customize colors:**
```js
// app/tailwind.config.mjs
colors: {
  primary: '#0066ff' // Your brand color
}
```

**4. Deploy:**
- Click Vercel button above
- Wait 2 minutes
- ✅ Live!
